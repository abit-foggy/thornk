# thornk

A lean Linux Kbuild to Ninja and `thorn.build` converter powered by Pith and Thorn's embedded decompiler FFI. Minimal, zero-bloat, deterministic, in the Unix spirit.

## Installation

```bash
# Change TAG=stable to TAG=nightly for the nightly build
curl -fsSL https://raw.githubusercontent.com/abit-foggy/thornk/main/install.sh | TAG=stable bash
```
